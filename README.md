Бот-автоответчик, который подключается к **Telegram Business** и отвечает клиентам
от имени владельца аккаунта: сначала по базе знаний (FAQ), затем с помощью ИИ,
а если ИИ недоступен — запасными ответами. Полностью управляется через меню внутри
бота, включая админ-панель.

---

## Возможности

### Автоответчик
- Работает через **Telegram Business** (`business_connection`): отвечает в личных чатах
  владельца, пока тот не зашёл в диалог.
- Настраивается **по каждому чату**: включить/выключить, расписание, роль чата.
- Пауза между сообщением клиента и ответом (`AUTO_REPLY_DELAY`) — выглядит естественно.

### База знаний (FAQ)
- Матчинг вопроса клиента с FAQ по порогу схожести (`FAQ_MATCH_THRESHOLD`).
- Ответы FAQ поддерживают **все типы контента Telegram**: текст (с форматированием и
  entities), фото, видео, аудио, голосовые, документы, стикеры, альбомы (media group).
- Лимит записей: `FREE_FAQ_LIMIT` (free) / `PREMIUM_FAQ_LIMIT` (premium).

### Искусственный интеллект
- Несколько провайдеров с **автоматическим переключением** при сбоях и cooldown:
  OpenRouter, Gemini, Groq, DeepSeek, OpenAI и любые OpenAI-совместимые.
- **Память диалога**: ИИ получает последние ~10 сообщений переписки и отвечает в контексте.
- **Профиль владельца** задаёт характер и инструкцию: имя, возраст, пол, родной/главный
  язык, темы, развёрнутое описание («главная инструкция»). ИИ говорит **от имени владельца**
  и следует приоритету языка: главная инструкция → родной язык → разрешённые языки.
- **Защита от утечки «мыслей»**: если ИИ присылает служебные рассуждения
  (`User Safety:`, `Rule 7 says`, `<reasoning>`, «the user is asking» и т.п.),
  санитайзер **вычищает их и сохраняет настоящий ответ**. Если после очистки ничего
  не осталось — ответ отбрасывается и уходит запасной текст (AI-слот возвращается).
- Квоты ИИ на владельца в день, учёт попыток/успехов по провайдерам.

### Команда «стоп ии»
- Если клиент раздражён или не хочет говорить с ботом, ИИ может предложить команду.
- Команды `стоп ии`, `stop ai`, `/stop` (и варианты) **приостанавливают все автоответы в этом чате**
  и уведомляют владельца. Возобновление — через «Диалоги → Возобновить».
- Сообщение самого владельца также приостанавливает чат и отменяет ожидающий ответ бота.

### Запасные ответы
- Два запасных текста, которые **чередуются бесконечно** (бот не замолкает).
- Ко второму запасному ответу добавляется **промо-подпись** с реферальной ссылкой.
  Ссылка вшивается в текст как **кликабельный гипертекст** (HTML `<a>`), а не голый URL.
  - Шаблон задаётся админом (`promo_signature_text`), плейсхолдеры:
    - `{link}` → ссылка-«подробнее»;
    - `{link:свой текст}` → ссылка с произвольным текстом-якорем.

### Отчёт «кто писал сегодня»
- Два раза в день, в **12:00 и 19:00** по часовому поясу владельца, бот присылает список
  чатов, в которых **он отвечал сегодня**. Если ответов не было — отчёт не отправляется.
- Учитывает часовой пояс каждого владельца (`timezone`).

### Профиль и настройки
- Меню профиля с кнопками: пол, язык (кнопки + свой вариант), готовые **шаблоны** описания
  ИИ (вежливый помощник, консультант продаж, поддержка, строго по фактам, языковые пресеты)
  или свой текст.
- Настройки языков, расписания, часового пояса, промо-подписи.

### Рефералы и Premium
- Реферальная программа со ссылкой и бонусами.
- Premium-тариф: расширенные лимиты, отключение промо-подписи и т.д.
- Оплата звёздами Telegram + ручной способ подтверждения.

### Админ-панель
- Статистика, управление пользователями (поиск, пагинация, карточка пользователя).
- **Блокировка** пользователей и **сброс текстов профиля** (помогает, например, при
  превышении лимита 4096 символов).
- Смена тарифа пользователя.
- Глобальные настройки: стоп-темы, стоп-ответ, текст промо-подписи, цены/лимиты.
- Рассылка с подтверждением.
- Инструкция (guide) — любые типы сообщений.
- **Управление AI-провайдерами прямо из бота** (см. ниже).

## Управление провайдерами из бота (без правки кода)

Админ может задавать ключи и добавлять новых провайдеров внутри бота:

**Админ-панель → 🤖 AI-провайдеры → ➕ Добавить / ключи**

Мастер по шагам спросит:
1. **Название** (латиница/цифры/`_`, 2–32 символа). Если такое уже есть — ключ обновится.
2. **Тип API**: `OpenAI-совместимый`, `OpenAI` или `Gemini`.
3. **Base URL** (обязателен для OpenAI-совместимого; для OpenAI/Gemini можно `-`).
4. **API-ключ** (сообщение с ключом сразу удаляется из чата).
5. **Модель** (например `gpt-4o-mini`, `gemini-1.5-flash`, `llama-3.1-70b-versatile`).

Также в панели: включение/выключение 🟢🔴 каждого провайдера и изменение **порядка**
переключения. Ключи, заданные через бота, хранятся в БД и имеют приоритет над `.env`.

> Безопасность: ключи хранятся в базе данных сервера (в таблице `ai_providers`).
> Держите файл БД и сервер защищёнными. В админ-панели ключ показывается маскированно
> (`••••ABCD`). Доступ ко всем админ-функциям — только для `ADMIN_IDS`.

## Требования

- Python **3.12+** (локальная разработка велась на 3.13; Docker-образ — `python:3.12-slim`).
- Зависимости: `aiogram==3.31.0`, `aiosqlite`, `aiohttp`, `python-dotenv`, `tzdata`.
- Аккаунт с подключённым **Telegram Business** и бот, привязанный к бизнес-аккаунту.

Установка зависимостей:

```bash
pip install -r requirements.lock.txt
```

## Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | **Обязательно.** Токен бота от @BotFather |
| `ADMIN_IDS` | — | Telegram ID админов через запятую |
| `DB_PATH` | локальный файл | Путь к базе SQLite |
| `USE_AI` | `true` | Включить ИИ-ответы |
| `AI_TIMEOUT` | `40` | Таймаут запроса к ИИ, сек |
| `AI_MAX_TOKENS` | `350` | Максимум токенов ответа |
| `AI_PROVIDER_COOLDOWN` | `900` | Cooldown провайдера после сбоя, сек |
| `AI_PROVIDER_ORDER` | `openrouter,gemini,groq,deepseek,openai` | Порядок переключения |
| `OPENROUTER_API_KEY` / `OPENROUTER_MODEL` | `openrouter/free` | OpenRouter |
| `GEMINI_API_KEY` / `GEMINI_MODEL` | `gemini-2.5-flash-lite` | Gemini |
| `GROQ_API_KEY` / `GROQ_MODEL` | `openai/gpt-oss-20b` | Groq |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | `deepseek-v4-flash` | DeepSeek |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | — | OpenAI |
| `CUSTOM1..5_NAME/_API_KEY/_BASE_URL/_MODEL` | — | До 5 своих OpenAI-совместимых провайдеров |
| `AUTO_REPLY_DELAY` | `1.5` | Задержка перед ответом, сек |
| `FAQ_MATCH_THRESHOLD` | `0.78` | Порог схожести вопроса с FAQ |
| `FREE_FAQ_LIMIT` | `20` | Лимит FAQ для free |

```bash
# Windows (Git Bash)
```

## Архитектура (файлы)

- `bot.py` — хендлеры aiogram, middleware, бизнес-логика, админ-панель, планировщик отчётов.
- `database.py` — слой SQLite (aiosqlite), схема, миграции, все запросы.
- `ai_service.py` — провайдеры ИИ, ретраи/переключение, системный промпт, память диалога.
- `keyboards.py` — inline/reply-клавиатуры.
- `states.py` — FSM-состояния.
- `config.py` — загрузка `.env` и настройки.
- `matcher.py` — матчинг FAQ.
- `policy.py` — стоп-темы.

## Производительность и масштабирование

Расчёт на несколько тысяч пользователей:
- SQLite в режиме **WAL**, `synchronous=NORMAL`, `timeout=30`.
- Первичные ключи покрывают горячие запросы: `users.telegram_id`,
  `ai_usage(owner_id, day)`, `chat_settings(owner_id, chat_id)`,
  `business_connections.connection_id`.
- Индексы: `idx_faq_owner` (FAQ по владельцу), `idx_chat_history_lookup`
  (история диалога).
- Планировщик отчётов делает **один** bulk-запрос `get_all_users_timezones()`
  вместо обращения к БД по каждому пользователю; локальное время считается в памяти,
  к БД обращаются только владельцы в окне отчёта.
- История диалога хранится усечённой (последние ~20 сообщений на чат).

## Безопасность

- Все админ-функции защищены проверкой `is_admin()` (`ADMIN_IDS`).
- Premium-функции — проверкой тарифа.
- Заблокированные пользователи отсекаются outer-middleware (кроме админов).
- Тексты профиля/ответы обрезаются и экранируются, чтобы не превышать лимит 4096
  символов и не ломать HTML-разметку.
- Сообщения с API-ключами удаляются сразу после ввода.
